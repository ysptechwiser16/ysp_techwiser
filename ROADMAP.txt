# YSP Techwiser — Roadmap

## Project Summary
YSP Techwiser is a premium tech media website focused on smartphones, laptops, accessories, AI, reviews, guides, news, comparisons, videos, and creator collaborations. The site is built with Next.js, TypeScript, MongoDB Atlas, Mongoose, and a custom admin/CMS layer.

## Current State
- Core frontend pages are built
- Admin/auth foundation is in place
- MongoDB Atlas is connected
- Main route protection is working
- Comments API issue has been fixed
- The project is now in the refinement and launch-prep stage
