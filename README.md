# YSP Techwiser

YSP Techwiser is a premium technology media website built with Next.js, TypeScript, Tailwind CSS, Framer Motion, MongoDB, and NextAuth.

## Features

- Premium homepage and editorial landing pages
- Smartphone, laptop, AI, accessories, news, videos, comparisons, and collaborations pages
- Search and bookmarks
- Reviews and guides routes
- Admin dashboard and analytics
- MongoDB-powered content and seed scripts
- API routes for search, bookmarks, analytics, comments, submissions, CMS sync, and uploads
